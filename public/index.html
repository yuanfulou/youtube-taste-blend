Google OAuth 設定指南 (Google Cloud Console)

建立憑證時請注意「JavaScript 來源」與「重新導向 URI」的填法區別：

1️⃣ 已授權的 JavaScript 來源 (Authorized JavaScript origins)：

⚠️ 不可包含任何路徑 (Path)，也不可以 / 結尾：

http://localhost:3030

http://100.127.138.61:3030

2️⃣ 已授權的重新導向 URI (Authorized redirect URIs)：

填入包含 /auth/callback 的完整路徑：

http://localhost:3030/auth/callback

http://100.127.138.61:3030/auth/callback

3️⃣ 將 Client ID 與 Secret 貼入專案 .env 檔案：

GOOGLE_CLIENT_ID=你的_CLIENT_ID.apps.googleusercontent.com

GOOGLE_CLIENT_SECRET=你的_CLIENT_SECRET

💡 提示：在尚未設定金鑰前，您可以隨時點擊【一鍵示範資料】直接進行雙人品味比對與圖卡匯出體驗！
